# Group Performance Evaluation Checklist

## Setup

- [ ] Prediction task is defined
- [ ] Groups for comparison are defined
- [ ] Group sample sizes are checked
- [ ] Labels are available for each group

## Dataset checks

- [ ] Missing values checked by group
- [ ] Label distribution checked by group
- [ ] Duplicate records checked
- [ ] Train and test separation checked

## Metric checks

- [ ] Same metrics calculated for each group
- [ ] Positive prediction rate compared
- [ ] True positive rate compared
- [ ] False positive rate compared
- [ ] Results reviewed with sample sizes

## Interpretation

- [ ] Large differences investigated
- [ ] Data limitations documented
- [ ] Model limitations documented
- [ ] Follow-up actions recorded
