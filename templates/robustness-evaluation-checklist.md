# Robustness Evaluation Checklist

## Setup

- [ ] Robustness goal is defined
- [ ] Baseline dataset is defined
- [ ] Changed-input dataset is defined
- [ ] Metric is selected
- [ ] Acceptable performance drop is defined

## Test design

- [ ] Input changes are realistic
- [ ] Labels are checked
- [ ] Preprocessing is consistent
- [ ] Dataset quality is reviewed

## Results

- [ ] Baseline score calculated
- [ ] Changed-input score calculated
- [ ] Performance drop calculated
- [ ] Result compared with acceptable drop

## Interpretation

- [ ] Failure cases reviewed
- [ ] Root causes investigated
- [ ] Limitations documented
- [ ] Follow-up actions recorded
