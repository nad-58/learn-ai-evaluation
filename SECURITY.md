# Security Policy

## Reporting a security concern

Please do not publish sensitive vulnerability details in a public issue.

Send a concise report to `nadernejad.ehsan@gmail.com` including:

- the affected file or component;
- steps to reproduce;
- expected impact;
- any suggested mitigation.

## Scope

This policy covers security concerns in repository code, examples, dependencies, and automation workflows.

Documentation corrections and general improvement suggestions can be submitted through normal issues or pull requests.
