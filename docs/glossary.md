# Glossary

## AI Evaluation

The structured process of assessing whether an AI or machine learning system performs reliably for its intended task and operating conditions.

## Data Evaluation

Assessment of dataset quality, completeness, consistency, representativeness, splitting strategy, leakage risk, and label quality.

## Model Evaluation

Assessment of the model's predictive behaviour using suitable metrics, validation data, subgroup analysis, calibration, robustness tests, and error analysis.

## System-Level Evaluation

Assessment of how the model behaves after integration into a larger software or data pipeline, including latency, API behaviour, monitoring, and drift.

## Generalisation

The ability of a model to perform well on new data that was not used during training.

## Robustness

The ability of a model to remain stable under noise, perturbations, edge cases, and realistic changes in input data.

## Fairness

Evaluation of whether model performance or outcomes differ across relevant groups in a way that may be unacceptable for the intended use.

## Data Drift

A change in the statistical distribution of input data over time.

## Prediction Drift

A change in the distribution of model outputs over time.

## Concept Drift

A change in the relationship between input features and the target variable over time.
